# バレーコンディション

バレーボール選手が、身体測定・練習・筋力トレーニング・食事・コンディションを記録し、推定値と記録にもとづく提案を確認できるスマートフォン向けWebアプリです。複数ユーザーが利用でき、データはユーザーごとに分離して保存します。

> 開発段階（MVP）です。本番公開はまだ行っていません。公開前に必要な作業は [docs/SECURITY.md](docs/SECURITY.md) の「公開前チェックリスト」を参照してください。

## 主な機能（MVP）

| 機能 | 内容 |
| --- | --- |
| アカウント | メールアドレス＋パスワードの登録・ログイン、ログアウト、パスワード変更、データのエクスポート（JSON）、アカウント削除 |
| 初回登録 | 基本情報・身体測定・運動習慣・目標の4ステップ。すべて任意でスキップ可 |
| 栄養目標 | 基礎代謝量・消費エネルギー・PFCの推定。式・出典・適用条件・限界を画面に表示 |
| 食事 | 朝昼夕・間食の記録、食品検索、分量指定、お気に入り、よく食べる食品、お気に入りメニュー、前日のコピー、自炊レシピ、栄養不明の記録、日別・週別の推移 |
| 筋トレ | 種目・重量・回数・左右・RPE/RIR・休憩、前回記録の表示、推定1RM（参考値）、総負荷量の推移、テンプレート、過去メニューの再利用 |
| バレー練習 | 時間・強度・RPE・ジャンプ回数・スパイク本数・調子・疲労、週ごとの練習負荷 |
| ジャンプ測定 | 立位指高・最高到達点・ブロック最高到達点など。実測／自己申告／推定を区別し、ジャンプ高は両方実測の場合のみ算出 |
| コンディション | 睡眠・疲労・筋肉痛・調子・休養日・部位別の違和感/痛み。痛みの記録時は医療専門職への相談を案内（診断はしない） |
| ホーム | 今日の目標と摂取量、運動予定、コンディション、体重推移、筋力、ジャンプ、ルールベースの提案。最優先目標に応じて表示順を変更 |
| 分析 | 体重×ジャンプ高、スクワット×ジャンプ高、練習負荷×翌日の疲労、睡眠×調子、摂取量×体重変化の相関（8組未満は表示しない） |

未実装の機能は [docs/DESIGN.md](docs/DESIGN.md) の「MVPと将来機能」を参照してください。

## 技術スタック

- Next.js 16（App Router, Server Actions）/ React 19 / TypeScript（strict）
- PostgreSQL + Drizzle ORM（マイグレーションは `drizzle/` に SQL で管理）
- 認証：自前実装のセッション認証（scrypt によるパスワードハッシュ、DB にはセッショントークンのハッシュのみ保存）
- 入力検証：Zod
- UI：Tailwind CSS v4（グラフは外部ライブラリを使わず SVG で実装）
- テスト：Vitest、DB を使うテストは PGlite（WASM 版 PostgreSQL）で実行

選定理由は [docs/DESIGN.md](docs/DESIGN.md) に記載しています。

## ローカル起動

必要なもの：Node.js 20.9 以上、PostgreSQL 14 以上

```bash
npm install

# 接続文字列を設定（.env.local は Git 管理対象外）
cp .env.example .env.local
# .env.local の DATABASE_URL を自分の環境に合わせて編集

# データベース作成（例）
createdb volley_conditioning

# マイグレーションと初期データ（共通の筋トレ種目名）の投入
export $(grep -v '^#' .env.local | xargs)
npm run db:migrate

npm run dev   # http://localhost:3000
```

スマートフォンから確認する場合は、同じネットワーク上で `npm run dev -- -H 0.0.0.0` として PC の IP アドレスにアクセスしてください（開発時は HTTP のため、クッキーの Secure 属性は本番ビルドでのみ有効になります）。

## テスト・検証

```bash
npm run typecheck   # 型チェック
npm run lint        # ESLint
npm test            # 単体テスト・結合テスト（DBサーバー不要。PGlite を使用）
npm run build       # 本番ビルド
```

テストの内容：

- `src/lib/calc/*.test.ts`：計算ロジック（BMI、基礎代謝量、消費エネルギー、栄養目標、1RM、ジャンプ高、相関、提案ルール）
- `tests/auth.test.ts`：パスワードハッシュ、ログイン、ロックアウト、セッション期限・延長、パスワード変更、アカウント削除
- `tests/isolation.test.ts`：ユーザー間のデータ分離（他人のデータの参照・更新・削除・利用ができないこと）
- `tests/meals.test.ts`・`tests/targets.test.ts`・`tests/validation.test.ts`：食事記録、目標算出、入力値の境界値

## 食品データについて

食品成分データは同梱していません。現在は、利用者がパッケージの栄養成分表示などから食品を登録する方式です（出所を「栄養成分表示」「本人の推定値」として区別して保存）。

文部科学省「日本食品標準成分表」などの公的データを使う場合は、利用条件を確認したうえで CSV に変換し、次のコマンドで共通食品として取り込めます（形式はスクリプト冒頭のコメント参照）。

```bash
npm run foods:import -- ./foods.csv
```

## ディレクトリ構成

```
src/
  app/              画面（App Router）と Server Actions
    (auth)/         ログイン・新規登録
    (app)/          ログイン後の画面（ホーム・食事・筋トレ・練習・体・分析・設定）
    onboarding/     初回登録
    api/export/     データエクスポート
  components/       UI部品・グラフ
  lib/
    calc/           計算ロジック（純粋関数・単体テスト付き）
    db/             スキーマ・接続・初期データ
    repo/           データアクセス（すべてユーザーIDで絞り込み）
    services/       画面向けの集計（目標算出・ダッシュボード・分析）
    auth/           認証
drizzle/            マイグレーションSQL
scripts/            マイグレーション・食品取込
tests/              DBを使う結合テスト
docs/               設計・計算根拠・セキュリティ
```
